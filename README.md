# Open JET

一个可直接在浏览器中运行的 **3D 空战轰炸小游戏**（键盘 + 鼠标操作）。驾驶战斗机在现代城市、乡村公路、农田与城际铁路走廊上空自由飞行，用机炮扫射、用炸弹轰炸，看建筑在爆炸中倒塌——撞上建筑或地面则会坠毁。

纯前端、单文件、全中文、资源全部程序化生成。当前场景采用完整的天光 / 远雾 / 动态水面与低多边形建筑语言，双击 HTML 打开即玩。

---

## 快速开始

1. 用浏览器打开 `game.html`（桌面键鼠操作）
2. 输入地图种子（任意文字）生成随机地图；在预览图上拖动 / 增减敌方地面单位（防空车、导弹阵地）——不动就用默认布点；结算后可点「换张地图」重开地图界面
3. 点击「开始任务」
4. W / S 俯仰升降，A / D 横滚转向；按住鼠标左键扫射；按住右键显示落点图标（真实弹道预测）、松开投弹；滑动鼠标拖动视角；Alt 视角回正，左 Shift 加力，Tab 切换鼠标显隐

> 无需安装、无需构建、无后端。仅 Three.js 通过 CDN 加载，首次运行需联网。

## 操作方式

| 操作 | 控件 |
| --- | --- |
| 俯仰升降 | W / S |
| 横滚转向 | A / D |
| 机炮扫射 | 按住鼠标左键 |
| 轰炸 | 按住鼠标右键显示落点图标（真实弹道预测，红色贴地平铺），松开鼠标右键投弹 |
| 视角旋转 | 滑动鼠标 |
| 视角回正 | 点按 Alt 视角归正（锁定期间无效） |
| 视角锁定 | 按 R 锁定屏幕中心最近的单位（敌机 / 僚机 / 防空机枪 / 导弹阵地）；锁定相机与机身姿态完全解耦——WASD 滚转 / 俯仰 / 偏航不再影响取景，目标恒居画面正中，只能再按 R 解除 |
| 加力加速 | 按住左 Shift（速度 ×2.0，视野拉伸 + 轻微抖动，尾焰更长更亮、引擎声更响） |
| 关闭发动机 | 长按 Space：引擎声静音、尾焰熄灭，推力衰减带来减速（滑翔至约 55% 巡航速度）与低头下坠（约 1.4 秒收敛到 -30° 下滑角，下降率约 19 m/s）；松开后推力平滑恢复 |
| 光标显隐 | 按 Tab 切换（进入任务自动隐藏，结算时恢复） |

- **摧毁建筑**：机枪命中 10 次，或炸弹在爆炸半径内命中
- **坠毁**：撞到建筑或地面后进入坠毁动画，结算得分
- **HUD**：实时显示机体血条 / 得分 / 击毁敌方单位数 / 飞行高度
- **机体血量**：共 32 点，挨 32 发子弹坠毁（命中间有 0.22 秒无敌帧）；被导弹命中或撞建筑 / 地面立即坠毁
- **振动反馈**：开火、投弹、爆炸、撞击（设备支持时）
- **关发动机**：长按 Space 推力回落——减速至滑翔速度并低头下坠（约 1.4 秒收敛到 -30° 下滑角），可按 W 对抗拉起；松开后推力约 3 秒恢复

## 技术特性

- **单文件**：`game.html` 内嵌全部 CSS / JS，代码用 IIFE 包裹，全局仅暴露来自 CDN 的 `THREE`
- **CDN 依赖**：`https://cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js`（版本锁定）
- **零外部资源**：模型用基本几何体拼装，地形为种子驱动的解析函数（分层噪声叠加），音效为 Web Audio 合成，不加载任何图片 / 音频 / 模型文件
- **种子地图生成**：`mulberry32` PRNG + 值噪声 fBM 分层（地形 / 城市 / 河流 / 湖泊 / 村庄 / 道路 / 农田 / 树林 / 植被 / 云全部由种子决定）；同种子完全复现、不同种子全随机；开局 UI 支持 2D 预览（含道路 / 村庄 / 农田 / 树林图层）与地面单位布点，生成重地图时按钮会显示进行中状态
- **画面体系**：线性色彩输出、无全局色调压缩、只在 11km 外开始生效的线性远雾；程序化渐变天空与太阳光晕；玩家附近启用定向光实时投影，远处用软接地暗斑补足重量感；水面为实时波动着色器
- **城市道路接入**：`cityRoadLayout` 同时服务 GEN 与场景层。外部公路会枚举城市最外圈的真实直角路口，先裁掉伸进城市的旧路段，再从路口沿该街道的水平/垂直轴直出，并用最小转弯半径 `85m` 的三次曲线并入公路主线。接入线带独立宽度渐变，从城市街道宽度平滑过渡到公路宽度，随后统一进入道路高度场、建筑避让、预览与渲染
- **公路桥与纵坡**：`buildRoadField` 首次烘焙后调用 `designRoadBridges`，重新检测水跨、合并桥跨、设定水平桥面，并按允许坡度计算引道长度；引道使用三次平滑曲线，随后做全局限坡和桥端二次限坡。铁路使用同样的“两端标高包络 + 桥跨抬升 + 桥端逐点限坡”，相邻桥跨距离不足时自动抬高较低桥面，站点标高随最终线位调整。`auditBridgePlacement` 在全部地图层生成后复核桥面水平度、桥头纵坡和结构净空，并把结果写入 `GEN.bridgeAudit`
- **城际铁路**：车站从城市外缘的多个候选方位中试排，按可达性选择组合；铁路 A* 对城市 / 村庄 / 公路施加强避让成本。线位经 16 轮转角松弛、站台切向引线和近邻线段检查后再定桥位。单城地图保留车站与尽头线但不运行列车；双城地图必生成 MST 连接与列车。连续跨水 / 跨路区段使用单一水平桥面，普通引道通过 3.5% 限坡和 `buildRailField` 压实路基，桥跨本身保持恒高
- **性能优化**：`antialias:false`、`pixelRatio ≤ 1.5`、InstancedMesh 批量渲染植被与车流、每栋建筑只保留一个合并 Mesh、空间哈希加速建筑碰撞查询
- **键鼠操作**：WASD 飞行 + 鼠标（左键机炮 / 右键瞄准投弹 / 滑动视角 / Alt 回正），左 Shift 加力、Tab 切换鼠标光标，按住生效、松开停止
- **视觉风格**：低多边形简约卡通（MeshLambertMaterial 平面着色），与写实风格明确区分

## 代码结构（game.html）

按功能分块，主要函数一览：

| 模块 | 函数 |

## 开发说明

**锁定参数**：`CFG` 全部字段以及 `GUN_KILL_HITS`、`BOMB_RADIUS`、`WATER_LEVEL` 均经确认后锁定，请勿擅自改动；如需调整手感或数值，先与需求方确认。

**调试入口**：

- 所有数值集中在文件顶部 `CFG` 与三个常量
- 世界生成集中在文件前部 GEN 区块（保持纯函数；校验脚本按标记整段抽取）：种子 → `genWorld` → `terrainHeight` 分层取高；尺寸 / 密度常量（`WORLD_HALF`、网格段数、树木数）在区块顶部；改地形只改该区块
- 地图元素按「前层决定后层选址」的顺序在 GEN 区块内生成：`genVillages` → `genRoads`（MST + A*）→ `connectCityRoads`（外部公路接城市街道）→ `buildRoadField` → `designRoadBridges`（公路桥跨设计 / 检测 / 修正）→ 再次 `buildRoadField` → `genRailways`（车站多候选 + 铁路 A*）→ `buildRailField` → `genFields`（先 `genFarmsteads` 独立落位，再生成村庄外围田块和沿路地籍带）→ `genForests` → `auditBridgePlacement`。田地、树林、岩石、散生植被和自动布点都会避开铁路走廊；城市引道不会被当成乡村公路布置农庄或田带
- 场景层 `createRoads` / `createVillages` / `createVillageHouses` / `createFarmland` / `createForests` / `createRocks` 只读 `GEN`；民居登记进 `buildings` + 空间哈希（与城市建筑共用受击 / 摧毁逻辑），`startGame` 重建城市时会一并重建（`createVillageHouses`）
- 细碎几何（城市街道 / 人行道 / 街区地坪 / 楼体窗带 / 屋顶设备 / 村庄门窗烟囱 / 栅栏）统一进 `detBatch` 批次，`detReset()` 开批、`detBuild()` 合成一个 `BufferGeometry` 一次画完；**`createCity()` 内部会 `detReset()`，所以村庄细节必须在 `createCity()` 之后生成**（`buildWorld` 里已按此排序）
- 手工拼 `BufferGeometry` 之后**必须 `computeVertexNormals()`**（Lambert / Phong 没有法线属性会整片渲染成黑色）；贴地四边形的顶点绕序要保证法线朝上
- 城市建筑在落位前用 `roadOnFootprint()` 检查路面权重，村庄房屋用 `roadAt()` + 房屋间距检查，避免楼压路 / 房压房；改路网或建筑密度时注意这两处
- 植被与田边树篱都用 InstancedMesh（散生树 7500 / 灌木 11000 / 树篱 12000 / 岩石 620 / 森林树 13000），循环里**必须用 `dummy` 显式设置 position / rotation / scale 再 `updateMatrix()`**，否则会残留上一棵的变换
- 键鼠输入逻辑在 `bindKeyboardMouse()`（含左 Shift 加力、Tab 光标切换），相机偏移应用在 `updateCamera()`，视角回正在 `resetView()`
- 加力倍率集中在 `BOOST_MULT`（速度 / 尾焰 / 引擎声共用）；机炮准星预测在 `updateGunAim()`
- 敌方单位：射程 / 数量常量在「敌方单位」段顶部（`AAA_RANGE` / `SAM_RANGE` / `ENEMY_MAX`）；自动逻辑分别在 `updateAAA()` / `updateSAM()` / `updateEnemies()` / `updateThreats()`；玩家受击与血量在 `damagePlayer()`（上限 `G.hpMax`，默认 32）
- 投弹落点预测与图标在 `updateAim()`（弹道必须与 `dropBomb` 保持一致）；炸弹威力问题先查 `BOMB_RADIUS` 与 `spawnExplosion(pos, 3.6)` 的第二个参数

**历史决策（不要回退）**：

- 「拖拽屏幕任意位置调视角」已废弃；触屏按钮 + 摇杆也已替换，现为键盘鼠标操作版本（WASD + 鼠标，Alt 回正）
- 「窗户贴图写实建筑」已废弃，与卡通飞机风格不符
- 「任务目标建筑」已移除，现为自由飞行、自由破坏
- 锁定相机「刚性挂在机身姿态上」已废弃：改为“目标视线稳定系”每帧重建（机身姿态不得参与锁定取景，WASD 机动不影响视角）；旧 `CAMV_*` 瞄准解已删除
- 关闭发动机按键由「长按 Ctrl」改为「长按 Space」（2026-10-11）：Ctrl+W / Ctrl+T / Ctrl+Tab 等浏览器保留快捷键无法被网页屏蔽，长按 Ctrl 期间按 WASD 会触发关闭标签页等冲突
- 「关车只做音画效果」已废弃（2026-10-11）：改为真实动力学——推力回落（`G.thrust`）驱动减速（`curSpeed()` 滑翔下限 0.55×巡航）与低头下坠（约 1.4 秒收敛到 -30° 下滑角）；僚机编队速度下限同步放宽至 34
- 「与爆炸半径同尺寸的预瞄大圆环」已废弃（2026-10-11）：改为真实弹道落点 + 贴地平铺红色图标（机炮准星同款元素）；炸弹着地面改为地形与水面取高（水面在水面炸开，不再沉底）
- SAM 阵地「平板发射架（倾斜导弹）+ 帐篷营地」已废弃（2026-10-11）：改为长条 TEL 载具（垂直待发导弹、双发射筒、8 轮）+ 小房子营地；垂直发射系统无瞄准机构，载具静止并按地形坡向俯仰防插地
- 「塔式固定防空机枪」已废弃（2026-10-11）：改为通古斯卡式履带防空车（炮塔两侧双管机炮、四管交替开火）；SAM 阵地整体放大 3.2 倍（含导弹）、营地增至 5 栋（`SAM_SCALE` / `AAA_SCALE` 集中调参）
- 「固定地形 + 手调布点」已废弃（2026-10-16）：地图改为 8800×8800 种子生成（Minecraft 式分层噪声，1~2 城 / 1~2 山河 / 0~2 湖全随机；城市单座大小 1~3 倍浮动），地面单位由开局 UI 布点（默认 5 车 + 3 阵地，数量不限、可拖动 / 重排）；出生点固定南侧边缘，机头自动朝向最近城市
- 「只有城市与荒野的地图」已废弃（2026-10-17）：按《泰拉瑞亚》式逐层生成加入道路 / 村庄 / 农田 / 树林四类元素（前一层决定后一层选址）；村庄民居并入 `buildings` 空间哈希（可被机炮 / 炸弹摧毁、+10 分、不计入击毁数），道路走廊压平地形并在跨河处自动架桥
- 「地图只有大色块、没有实体细节」已废弃（2026-10-17 第二轮）：城市补街道网格 + 街区地坪 + 窗带 + 屋顶设备；村庄补十字土街 / 门窗烟囱 / 栅栏 / 水塔；农田改真垄沟几何 + 田边树篱 + 农舍；密度整体上调（村庄 6~9、田 70~115 片、林 10~14 片、散生树 7500 + 灌木 11000 + 岩石 620）；建筑与房屋落位前检查路面，修掉「楼建在路上」的穿模
- 「楼体条码立面 + 巨型村庄土路」已废弃（2026-10-17 第三轮视觉重构）：城市改为裙房 / 塔楼 / 退台 / 商业 / 公园混合街区，窗户改独立窗格；村庄缩到真实街道尺度并加入支路、前院、菜地、栅栏、教堂；道路补边线、桥台与连续护栏；植被改多树形、树篱改连续重叠；天空、雾、动态水面、软接地阴影与建筑合批统一接入
- 「工业园当作火车站」已废弃（2026-10-17）：删除 `createCityFringe` / `makeWarehouseBuilding` 及其集装箱场，改为真正的城际铁路系统。双城地图必须生成车站、线路和可往返运行的列车；轨道避开城市 / 村庄 / 公路，跨河与跨路采用高架桥
- 「公路只停到城市区块边缘」「公路桥固定水面上方 10m」已废弃（2026-10-17）：外部公路现在接入真实街道端头；道路桥面改为两岸较高点控制水平标高，桥台、盖梁和桥墩严格位于梁底以下。铁路桥同步改为恒高连续梁跨，转折角与桥头纵坡分开处理
- 「整块桥面板压在沥青下方」已废弃（2026-10-17 公路桥二次重构）：即使数值上低于路面，全宽顶板在斜视角仍会遮住车道。现在采用无顶板开顶箱梁，沥青是唯一可见桥面；桥跨设计与最终桥涵审计写入 `GEN.bridgeAudit`，40 种子抽检 `bErr=0`、桥面标高差 `0.000m`
- 「公路斜插进城市街区再补连接片」已废弃（2026-10-17）：外部公路现在从城市最外圈直角路口进入，沿街轴直出后用最小 85m 半径曲线并入；旧路端伸进城内的部分会被裁掉，接入段宽度从街道渐变到公路，不再出现分叉状大块沥青
- 战绩指标「击毁建筑」已废弃（2026-10-12）：改为「击毁敌方单位」（建筑只计分、不计入指标）；结算文案移除「主人」称呼；标题全面更名 **Open JET**（副标题 AIR STRIKE）

**已知限制 / 可扩展方向**：实时投影覆盖玩家附近约 1.2km，远距离仍以软接地暗斑为主；城市仍采用规则街区网格，尚未加入高架路、地铁和河岸建筑；当前只有单线城际铁路，尚无信号联锁、多列车会让或地下段；碎片只受重力、不互相碰撞；当前为键鼠版本，暂未保留触屏控件（旧触屏版备份在 `game-touch.html`）；可扩展得分飘字、连击奖励、昼夜循环、额外武器等。
