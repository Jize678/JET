# Open JET

一个可直接在浏览器中运行的 **3D 空战轰炸小游戏**（键盘 + 鼠标操作）。驾驶战斗机在城市上空自由飞行，用机炮扫射、用炸弹轰炸，看建筑在爆炸中倒塌——撞上建筑或地面则会坠毁。

纯前端、单文件、全中文、资源全部程序化生成，双击 HTML 打开即玩。

---

## 快速开始

1. 用浏览器打开 `game.html`（桌面键鼠操作）
2. 输入地图种子（任意文字）生成随机地图；在预览图上拖动 / 增减敌方地面单位（防空车、导弹阵地）——不动就用默认布点；结算后可点「换张地图」重开地图界面
3. 点击「开始任务」
4. W / S 俯仰升降，A / D 横滚转向；按住鼠标左键扫射；按住右键显示落点图标（真实弹道预测）、松开投弹；滑动鼠标拖动视角；Alt 视角回正，左 Shift 加力，Tab 切换鼠标显隐

> 无需安装、无需构建、无后端。仅 Three.js 通过 CDN 加载，首次运行需联网。

## 操作方式

| 操作 | 控件 |
| --- | --- |
| 俯仰升降 | W / S |
| 横滚转向 | A / D |
| 机炮扫射 | 按住鼠标左键 |
| 轰炸 | 按住鼠标右键显示落点图标（真实弹道预测，红色贴地平铺），松开鼠标右键投弹 |
| 视角旋转 | 滑动鼠标 |
| 视角回正 | 点按 Alt 视角归正（锁定期间无效） |
| 视角锁定 | 按 R 锁定屏幕中心最近的单位（敌机 / 僚机 / 防空机枪 / 导弹阵地）；锁定相机与机身姿态完全解耦——WASD 滚转 / 俯仰 / 偏航不再影响取景，目标恒居画面正中，只能再按 R 解除 |
| 加力加速 | 按住左 Shift（速度 ×2.0，视野拉伸 + 轻微抖动，尾焰更长更亮、引擎声更响） |
| 关闭发动机 | 长按 Space：引擎声静音、尾焰熄灭，推力衰减带来减速（滑翔至约 55% 巡航速度）与低头下坠（约 1.4 秒收敛到 -30° 下滑角，下降率约 19 m/s）；松开后推力平滑恢复 |
| 光标显隐 | 按 Tab 切换（进入任务自动隐藏，结算时恢复） |

- **摧毁建筑**：机枪命中 10 次，或炸弹在爆炸半径内命中
- **坠毁**：撞到建筑或地面后进入坠毁动画，结算得分
- **HUD**：实时显示机体血条 / 得分 / 击毁敌方单位数 / 飞行高度
- **机体血量**：共 32 点，挨 32 发子弹坠毁（命中间有 0.22 秒无敌帧）；被导弹命中或撞建筑 / 地面立即坠毁
- **振动反馈**：开火、投弹、爆炸、撞击（设备支持时）
- **关发动机**：长按 Space 推力回落——减速至滑翔速度并低头下坠（约 1.4 秒收敛到 -30° 下滑角），可按 W 对抗拉起；松开后推力约 3 秒恢复

## 游戏内容

| 元素 | 说明 |
| --- | --- |
| 地形 | 8800×8800 种子生成（Minecraft 式分层噪声：基础起伏 → 山脉 → 河流 → 湖泊 → 城市整平 → 出生地整平），同一种子得到同一张图 |
| 山脉 | 1~2 条山系由种子随机（位置 / 走向 / 峰高），带岩地、雪线配色 |
| 城市 | 1~2 座由种子随机选址；单座大小 1~3 倍浮动（以 620×600 为 1 倍，街区 / 道路 / 楼高等比缩放；配色不变：蓝系楼体 + 暖色屋顶） |
| 河流 | 1~2 条正弦叠加的蜿蜒河道，贯穿地图 |
| 湖泊 | 0~2 个，带谐波扰动的不规则岸线 |
| 水面 | 半透明材质，高度 4 |
| 植被 | 约 1850 棵松树（密度不变、噪声成簇分布；InstancedMesh 批量渲染，自动避开城市 / 水面 / 高地） |
| 可摧毁建筑 | 机炮累计命中 10 次或炸弹波及即摧毁，带碎片飞散 |
| 机炮准星 | 按住左键扫射时在弹着点显示十字准星（`updateGunAim`，随距离缩放） |
| 投弹落点图标 | 按住右键时按真实弹道（挂点偏移 / 初速 −8 / 逐帧重力）预测落点，在落点平铺红色图标（与地面 / 坡面平行、随视距缩放）；水面投放落在水面上 |
| 防空机枪 | 通古斯卡式履带防空车（炮塔两侧各双管机炮，四管交替开火；车体按地形坡向俯仰）+ 随车小房子营地；位置由开局地图 UI 布置（默认 5 辆，数量不限、可拖动）；炮塔自动跟踪玩家，进入射程后连发集中的曳光弹（弹流可通过机动甩开）；可被机炮/炸弹摧毁（+60 分） |
| 防空导弹阵地 | 长条 TEL 载具（底盘 + 驾驶室 + 8 轮 + 双垂直发射筒；待发导弹垂直向上，筒口冷发射；整体等比放大 2 倍，导弹同缩放）+ 小房子营地（5 栋小屋 + 弹药箱 / 油桶 / 沙袋）；位置由开局地图 UI 布置（默认 3 处，数量不限、可拖动）；锁定玩家后发射追踪导弹（可急转或加力甩开）；可被摧毁（+90 分） |
| 敌机 | 从地图边缘周期性进入（同时最多 3 架），追击并射击玩家；可被机炮击落（+150 分） |
| 僚机 ×2 | 蓝色翼尖涂装的友军 AI：无敌机时编队跟随玩家侧后方；发现敌机即自发脱离编队迎战（提前量追击 + 咬尾控速；纯战斗机，不对地面单位反应；击落后 20 秒归队）；敌机会在玩家与僚机之间分摊目标 |
| 特效 | 闪光、火球、冲击波环、火花、烟雾、建筑碎片（自动生命周期管理） |
| 音效 | 引擎（随俯仰变调）、机炮、爆炸，全部 Web Audio 实时合成 |

## 技术特性

- **单文件**：`game.html` 内嵌全部 CSS / JS，代码用 IIFE 包裹，全局仅暴露来自 CDN 的 `THREE`
- **CDN 依赖**：`https://cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js`（版本锁定）
- **零外部资源**：模型用基本几何体拼装，地形为种子驱动的解析函数（分层噪声叠加），音效为 Web Audio 合成，不加载任何图片 / 音频 / 模型文件
- **种子地图生成**：`mulberry32` PRNG + 值噪声 fBM 分层（地形 / 城市 / 河流 / 湖泊 / 植被 / 云全部由种子决定）；同种子完全复现、不同种子全随机；开局 UI 支持 2D 预览与地面单位布点
- **性能优化**：`antialias:false`、`pixelRatio ≤ 1.5`、InstancedMesh 批量渲染植被、空间哈希加速建筑碰撞查询
- **键鼠操作**：WASD 飞行 + 鼠标（左键机炮 / 右键瞄准投弹 / 滑动视角 / Alt 回正），左 Shift 加力、Tab 切换鼠标光标，按住生效、松开停止
- **视觉风格**：低多边形简约卡通（MeshLambertMaterial 平面着色），与写实风格明确区分

## 开发说明

**锁定参数**：`CFG` 全部字段以及 `GUN_KILL_HITS`、`BOMB_RADIUS`、`WATER_LEVEL` 均经确认后锁定，请勿擅自改动；如需调整手感或数值，先与需求方确认。

**调试入口**：

- 所有数值集中在文件顶部 `CFG` 与三个常量
- 世界生成集中在文件前部 GEN 区块（保持纯函数；校验脚本按标记整段抽取）：种子 → `genWorld` → `terrainHeight` 分层取高；尺寸 / 密度常量（`WORLD_HALF`、网格段数、树木数）在区块顶部；改地形只改该区块
- 键鼠输入逻辑在 `bindKeyboardMouse()`（含左 Shift 加力、Tab 光标切换），相机偏移应用在 `updateCamera()`，视角回正在 `resetView()`
- 加力倍率集中在 `BOOST_MULT`（速度 / 尾焰 / 引擎声共用）；机炮准星预测在 `updateGunAim()`
- 敌方单位：射程 / 数量常量在「敌方单位」段顶部（`AAA_RANGE` / `SAM_RANGE` / `ENEMY_MAX`）；自动逻辑分别在 `updateAAA()` / `updateSAM()` / `updateEnemies()` / `updateThreats()`；玩家受击与血量在 `damagePlayer()`（上限 `G.hpMax`，默认 8）
- 投弹落点预测与图标在 `updateAim()`（弹道必须与 `dropBomb` 保持一致）；炸弹威力问题先查 `BOMB_RADIUS` 与 `spawnExplosion(pos, 3.6)` 的第二个参数

**历史决策（不要回退）**：

- 「拖拽屏幕任意位置调视角」已废弃；触屏按钮 + 摇杆也已替换，现为键盘鼠标操作版本（WASD + 鼠标，Alt 回正）
- 「窗户贴图写实建筑」已废弃，与卡通飞机风格不符
- 「任务目标建筑」已移除，现为自由飞行、自由破坏
- 锁定相机「刚性挂在机身姿态上」已废弃：改为“目标视线稳定系”每帧重建（机身姿态不得参与锁定取景，WASD 机动不影响视角）；旧 `CAMV_*` 瞄准解已删除
- 关闭发动机按键由「长按 Ctrl」改为「长按 Space」（2026-10-11）：Ctrl+W / Ctrl+T / Ctrl+Tab 等浏览器保留快捷键无法被网页屏蔽，长按 Ctrl 期间按 WASD 会触发关闭标签页等冲突
- 「关车只做音画效果」已废弃（2026-10-11）：改为真实动力学——推力回落（`G.thrust`）驱动减速（`curSpeed()` 滑翔下限 0.55×巡航）与低头下坠（约 1.4 秒收敛到 -30° 下滑角）；僚机编队速度下限同步放宽至 34
- 「与爆炸半径同尺寸的预瞄大圆环」已废弃（2026-10-11）：改为真实弹道落点 + 贴地平铺红色图标（机炮准星同款元素）；炸弹着地面改为地形与水面取高（水面在水面炸开，不再沉底）
- SAM 阵地「平板发射架（倾斜导弹）+ 帐篷营地」已废弃（2026-10-11）：改为长条 TEL 载具（垂直待发导弹、双发射筒、8 轮）+ 小房子营地；垂直发射系统无瞄准机构，载具静止并按地形坡向俯仰防插地
- 「塔式固定防空机枪」已废弃（2026-10-11）：改为通古斯卡式履带防空车（炮塔两侧双管机炮、四管交替开火）；SAM 阵地整体放大 2 倍（含导弹）、营地增至 5 栋（`SAM_SCALE` / `AAA_SCALE` 集中调参）
- 「固定地形 + 手调布点」已废弃（2026-10-16）：地图改为 8800×8800 种子生成（Minecraft 式分层噪声，1~2 城 / 1~2 山河 / 0~2 湖全随机；城市单座大小 1~3 倍浮动），地面单位由开局 UI 布点（默认 5 车 + 3 阵地，数量不限、可拖动 / 重排）；出生点固定南侧边缘朝北进场
- 战绩指标「击毁建筑」已废弃（2026-10-12）：改为「击毁敌方单位」（建筑只计分、不计入指标）；结算文案移除「主人」称呼；标题全面更名 **Open JET**（副标题 AIR STRIKE）

**已知限制 / 可扩展方向**：碎片只受重力、不互相碰撞；当前为键鼠版本，暂未保留触屏控件（旧触屏版备份在 `game-touch.html`）；可扩展得分飘字、连击奖励、昼夜光照、额外武器、敌机等。
