# Open JET

一个可直接在浏览器中运行的 **3D 空战轰炸小游戏**（键盘 + 鼠标操作）。驾驶战斗机在现代城市、乡村公路、农田与城际铁路走廊上空自由飞行，用机炮扫射、用炸弹轰炸，看建筑在爆炸中倒塌——撞上建筑或地面则会坠毁。

纯前端、单文件、全中文、资源全部程序化生成。当前场景采用完整的天光 / 远雾 / 动态水面与低多边形建筑语言，双击 HTML 打开即玩。

---

## 快速开始

1. 用浏览器打开 `game.html`（桌面键鼠操作）
2. 在种子界面输入任意文字，或点「随机」换一个种子，然后点击「生成世界」
3. 生成界面会显示当前阶段、阶段序号和总进度；世界数据与全部场景层完成后进入战术部署
4. 部署界面左侧为地图，右侧调整防空车 / 导弹阵地数量，并在「战场光影」中选择「无光影 / 黄金斜阳 / 低饱和阴天」；也可以直接拖动地图标记，点击标记删除，点「重新布防」恢复自动布点
5. 进入机库，选择「α型」或「歼-10」，再点击「开始任务」进入飞行
6. W / S 俯仰升降，A / D 横滚转向；按住鼠标左键扫射；按住右键显示落点图标（真实弹道预测）、松开投弹；滑动鼠标拖动视角；Alt 视角回正，左 Shift 加力，Tab 切换鼠标显隐
7. 歼-10 先按 R 锁定敌方单位，再按 F 发射霹雳导弹；导弹会持续追踪发射时锁定的目标

> 无需安装、无需构建、无后端。仅 Three.js 通过 CDN 加载，首次运行需联网。

## 操作方式

| 操作 | 控件 |
| --- | --- |
| 俯仰升降 | W / S |
| 横滚转向 | A / D |
| 机炮扫射 | 按住鼠标左键 |
| 轰炸 | 按住鼠标右键显示落点图标（真实弹道预测，红色贴地平铺），松开鼠标右键投弹 |
| 视角旋转 | 滑动鼠标 |
| 视角回正 | 点按 Alt 视角归正（锁定期间无效） |
| 视角锁定 | 按 R 锁定屏幕中心最近的单位（敌机 / 僚机 / 防空机枪 / 导弹阵地）；锁定相机与机身姿态完全解耦——WASD 滚转 / 俯仰 / 偏航不再影响取景，目标恒居画面正中，只能再按 R 解除 |
| 霹雳导弹 | 仅歼-10：先按 R 锁定敌机 / 防空车 / 导弹阵地，再按 F 发射；4 枚挂载、单发冷却 1.05 秒、发射后自动追踪 |
| 加力加速 | 按住左 Shift（速度 ×2.0，视野拉伸 + 轻微抖动，尾焰更长更亮、引擎声更响） |
| 关闭发动机 | 长按 Space：引擎声静音、尾焰熄灭，推力衰减带来减速（滑翔至约 55% 巡航速度）与低头下坠（约 1.4 秒收敛到 -30° 下滑角，下降率约 19 m/s）；松开后推力平滑恢复 |
| 光标显隐 | 按 Tab 切换（进入任务自动隐藏，结算时恢复） |

- **摧毁建筑**：机枪命中 10 次，或炸弹在爆炸半径内命中
- **摧毁场景目标**：树木、道路 / 铁路电线杆、列车车厢与车站模块均可受机炮和炸弹破坏；树木保留树桩，电线杆断线，列车车头被毁后停驶
- **坠毁**：撞到建筑或地面后进入坠毁动画，结算得分
- **HUD**：实时显示机体血条 / 得分 / 击毁敌方单位数 / 飞行高度；歼-10 额外显示霹雳余弹、冷却和锁定状态
- **霹雳制导**：发射必须存在有效的 R 锁定敌方目标；友军不可被霹雳攻击。发射后锁定目标引用，即使解除 R 视角锁定也继续制导；目标先被摧毁时导弹失去目标并自毁
- **机体血量**：共 32 点，挨 32 发子弹坠毁（命中间有 0.22 秒无敌帧）；被导弹命中或撞建筑 / 地面立即坠毁
- **振动反馈**：开火、投弹、爆炸、撞击（设备支持时）
- **关发动机**：长按 Space 推力回落——减速至滑翔速度并低头下坠（约 1.4 秒收敛到 -30° 下滑角），可按 W 对抗拉起；松开后推力约 3 秒恢复

## 技术特性

- **单文件**：`game.html` 内嵌全部 CSS / JS，代码用 IIFE 包裹，全局仅暴露来自 CDN 的 `THREE`
- **CDN 依赖**：`https://cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js`（版本锁定）
- **零外部资源**：模型用基本几何体拼装，地形为种子驱动的解析函数（分层噪声叠加），音效为 Web Audio 合成，不加载任何图片 / 音频 / 模型文件
- **红色纯色横屏开局流程**：种子输入 → 分阶段生成 → 左右分栏战术部署。世界数据和 Three.js 场景分别通过 `genWorldSteps` / `buildWorldSteps` 分阶段驱动，阶段之间主动让出渲染帧，进度条能真实反映当前构建环节；同步入口 `genWorld` / `buildWorld` 继续保留给校验脚本
- **座驾选择机库**：部署页确认地面防线与光影后进入独立的三维机库页，可在「α型」与「歼-10」之间切换；两架机体都支持按住拖动旋转预览、返回部署页修改设置，再由座驾页开始任务
- **歼-10 霹雳火控**：R 锁定结果带敌我类型，F 键只允许对锁定敌机 / 防空车 / 导弹阵地发射；独立玩家导弹池不占用敌方 SAM 的 3 枚并发上限，包含弹药、挂架显隐、1.05 秒冷却、加速、预测拦截、近失自毁、目标先毁自毁、命中计分和离场清理
- **动态城市数量**：移除固定 1~2 座计数，城市落位改为持续采样，仅在连续 140 次失败后停止；河流先于城市生成，城市落位时避开完整河道走廊，保证多城地图仍有水系
- **地形优先交通生成**：山脉、河流、湖泊、城市、村庄处理完后先烘焙基础地形；道路与铁路的 A*、站场高度和路基压平全部读取这份基础高度场。最终地形烘焙后再执行 `auditTransportClearance`，按公路全宽和铁路轨面逐点采样，发现地面高于目标路面时在走廊内向下修正，并写入 `GEN.transportAudit`
- **种子地图生成**：`mulberry32` PRNG + 值噪声 fBM 分层（地形 / 城市 / 河流 / 湖泊 / 村庄 / 道路 / 农田 / 树林 / 草甸 / 植被 / 云全部由种子决定）；同种子完全复现、不同种子全随机；开局 UI 通过种子页、阶段进度页、战术部署页三步完成，部署页支持 2D 预览（含道路 / 村庄 / 农田 / 树林 / 草甸图层）与地面单位布点
- **大面积森林**：主森林片区从 8~11 个提升到 22~31 个候选落位，配合 18 个中小树丛，实际通常形成 34~47 个板块；单片尺寸和林核数量同步上调，森林实例上限从 14500 提升到 30000
- **车站端点与铁路桥梁**：每城生成经过“站台出口 220m 净空”筛选的站型候选，并通过 MST 树形 DP 联合选择唯一车站；每条线路从站台两端之一切向出线。`RAIL_MIN_CURVE_RADIUS = 60m` 是硬约束；候选路径超过曲率即被淘汰，兜底曲线使用切向 Hermite 控制并在 8m 密采样后反复平滑。桥涵检测沿每段轨道采样道路和水系，单点桥标记会扩展成至少一条桥跨，桥面强制保持水平
- **铁路全里程纵坡约束**：站台轨面和桥面作为固定高度约束，所有中间节点用双向坡度投影求可行纵断面；`RAIL_MAX_GRADE = 20%` 对整条线路硬生效，包括站台下的第一段和最后一段。桥面找平后无法接入时，联合选址会尝试其他站台出口、站址或绕行线路；铁路连通性不会被静默放弃。60 个独立种子的 234 座城市均“一站一线”，174 条城际线全部连通，坡度、曲率和端点失配均为 0 失败；另以 8 个种子复核桥涵标记与全宽穿模，结果同为 0 失败
- **低地填充**：农田采用村庄组团、沿路地籍带、平缓腹地组团和粗网格补区四层生成；田块尺寸上调并增加防风林。剩余低地再铺草甸 / 牧场，带树丛、孤树、灌木和草垛；散生树允许进入低海拔平原，出生点净空缩小，道路树带加密，减少没有任何土地利用信息的大块纯绿区域
- **山体防断崖**：每座山先生成约 129×129 的解析高度场，再经过低通和坡度限制；全部道路、铁路、站场和农庄高度处理完成后，再把整张地图烘焙为 512×512 高度场，以行 / 列双向限坡削掉剩余陡壁。`terrainHeight` 之后统一读取该高度场，视觉、碰撞、布点和场景贴地保持一致
- **三档光影预设**：部署页可选「无光影 / 黄金斜阳 / 低饱和阴天」。黄金斜阳使用 ACES、sRGB、低角度暖光与冷色天空补光；阴天战争使用灰蓝低饱和天空、柔和主光、密集远雾与胶片扫描线；无光影保留基础线性色彩并关闭实时阴影。三档均带独立雾、天空、云色与屏幕暗角参数
- **画面体系**：程序化渐变天空与太阳光晕；近景使用跟随飞机的 2048 软阴影贴图（建筑、地形、车站、列车与电线杆投影），远景用接地暗斑和大气透视补足重量；水面为实时波动着色器。阴影相机覆盖约 1.96km，并随玩家移动按 90m 步长更新
- **方形地图边界**：地形范围为 8800×8800，飞行软边界改为与地形同形的方形 `±4380m`；距边界 620m 提示并缓转回中心，斜向飞行不再被内切圆提前截断
- **可破坏物空间查询**：树木 / 电线杆 / 车站模块进入独立空间哈希，子弹只查询附近网格；列车使用逐车厢 OBB 判定，避免为两万多棵树做全量逐帧扫描
- **城市道路接入**：`cityRoadLayout` 同时服务 GEN 与场景层。外部公路会枚举城市最外圈的真实直角路口，先裁掉伸进城市的旧路段，再从路口沿该街道的水平/垂直轴直出，并用最小转弯半径 `85m` 的三次曲线并入公路主线。接入线带独立宽度渐变，从城市街道宽度平滑过渡到公路宽度，随后统一进入道路高度场、建筑避让、预览与渲染
- **公路桥与纵坡**：`buildRoadField` 首次烘焙后调用 `designRoadBridges`，重新检测水跨、合并桥跨、设定水平桥面，并按允许坡度计算引道长度；引道使用三次平滑曲线，随后做全局限坡和桥端二次限坡。铁路使用同样的“两端标高包络 + 桥跨抬升 + 桥端逐点限坡”，相邻桥跨距离不足时自动抬高较低桥面，站点标高随最终线位调整。`auditBridgePlacement` 在全部地图层生成后复核桥面水平度、桥头纵坡和结构净空，并把结果写入 `GEN.bridgeAudit`
- **城际铁路**：车站从城市外缘的多个候选方位中试排，按可达性选择组合；铁路 A* 对城市 / 村庄 / 公路施加强避让成本。线位经 16 轮转角松弛、站台切向引线和近邻线段检查后再定桥位。单城地图也保留正式车站与站内贯通线；多城地图用 MST、补边和孤立城市紧急接驳保证一张连通网。连续跨水 / 跨路区段使用单一水平桥面，桥头引道优先按 4% 设计，最终全线由 20% 硬上限统一求解，`buildRailField` 压实普通路基，桥跨本身保持恒高
- **性能优化**：`antialias:false`、`pixelRatio ≤ 1.5`、InstancedMesh 批量渲染植被、电线杆与车流、每栋建筑只保留一个合并 Mesh、空间哈希加速建筑与场景可破坏物查询、阴影贴图仅在玩家移动一定距离后重算
- **键鼠操作**：WASD 飞行 + 鼠标（左键机炮 / 右键瞄准投弹 / 滑动视角 / Alt 回正），左 Shift 加力、Tab 切换鼠标光标，按住生效、松开停止
- **视觉风格**：低多边形简约卡通（MeshLambertMaterial 平面着色），与写实风格明确区分

## 开发说明

**锁定参数**：`CFG` 全部字段以及 `GUN_KILL_HITS`、`BOMB_RADIUS`、`WATER_LEVEL` 均经确认后锁定，请勿擅自改动；如需调整手感或数值，先与需求方确认。

**调试入口**：

- 所有数值集中在文件顶部 `CFG` 与三个常量
- 世界生成集中在文件前部 GEN 区块（保持纯函数；校验脚本按标记整段抽取）：种子 → `genWorld` → `terrainHeight` 分层取高；尺寸 / 密度常量（`WORLD_HALF`、网格段数、树木数）在区块顶部；改地形只改该区块
- 地图元素按「前层决定后层选址」的顺序在 GEN 区块内生成：`genVillages` → `bakeTerrainHeightGrid(g, true)` 定稿基础地形 → `genRoads`（MST + A*）→ `connectCityRoads` → `buildRoadField` → `designRoadBridges` → 再次 `buildRoadField` → `genRailways` → `buildRailField` → `genFields` → `genForests` → `genMeadows` → `genRocks` → 最终 `bakeTerrainHeightGrid(g)` → `auditTransportClearance` → `auditBridgePlacement`。公路、铁路和站场的选线与高度计算必须读取 `groundHeight()` / 基础高度场，不能再用未定稿的 `rawHeight` 作为最终地面
- 场景层 `createRoads` / `createVillages` / `createVillageHouses` / `createFarmland` / `createForests` / `createRocks` 只读 `GEN`；民居登记进 `buildings` + 空间哈希（与城市建筑共用受击 / 摧毁逻辑），`startGame` 重建城市时会一并重建（`createVillageHouses`）
- 细碎几何（城市街道 / 人行道 / 街区地坪 / 楼体窗带 / 屋顶设备 / 村庄门窗烟囱 / 栅栏）统一进 `detBatch` 批次，`detReset()` 开批、`detBuild()` 合成一个 `BufferGeometry` 一次画完；**`createCity()` 内部会 `detReset()`，所以村庄细节必须在 `createCity()` 之后生成**（`buildWorld` 里已按此排序）
- 手工拼 `BufferGeometry` 之后**必须 `computeVertexNormals()`**（Lambert / Phong 没有法线属性会整片渲染成黑色）；贴地四边形的顶点绕序要保证法线朝上
- 城市建筑在落位前用 `roadOnFootprint()` 检查路面权重，村庄房屋用 `roadAt()` + 房屋间距检查，避免楼压路 / 房压房；改路网或建筑密度时注意这两处
- 植被与田边树篱都用 InstancedMesh（散生树 9600 / 灌木 9200 / 树篱 70000 / 岩石 620 / 森林树 30000），循环里**必须用 `dummy` 显式设置 position / rotation / scale 再 `updateMatrix()`**，否则会残留上一棵的变换
- 树木、电线杆、车站模块创建时自动登记到 `propHash`；改变树木实例矩阵、车站模块可见性或电线杆线段后，必须同步更新 `instanceMatrix.needsUpdate` 或对应 `BufferAttribute`
- 森林形状由 `forestCoverage(f,x,z)` 统一驱动；地面色、树木采样、预览和自动布点都不得再退回单个椭圆。林地空地由 `clearings` 扣除，修改覆盖阈值时需复查边缘是否出现硬切
- 草甸由 `meadowCoverage(f,x,z)` 统一驱动地面色与草甸植被；农田生成在草甸之前，草甸只填剩余低地。新增田块类型时需同时考虑 `insideField()`、预览颜色和防风林密度
- 山体高度不要直接改回高频解析叠加；`mountainContribution` 只用于烘焙 `m.field`，运行期由 `sampleMountainField` 双线性读取。生成末尾的 `bakeTerrainHeightGrid` 还会把道路 / 铁路 / 站场造成的极端填挖统一限坡；若复查仍有连续陡壁，优先检查最终 512×512 高度场，而不是只调山体参数
- 光影参数集中在 `LIGHT_PRESETS` 与 `applyLightingPreset()`；若改阴影范围 / 太阳偏移，同时检查黄金斜阳和阴天战争两档，避免山体或建筑出现阴影断层
- 键鼠输入逻辑在 `bindKeyboardMouse()`（含左 Shift 加力、Tab 光标切换），相机偏移应用在 `updateCamera()`，视角回正在 `resetView()`
- 座驾通过 `AIRCRAFT_MODELS` 注册；新增或调整机体时同步名称、参数、工厂函数和机库卡片。歼-10 的独立挂架保存在 `plane.userData.plMissileSlots`
- R 锁定结果由 `findLockTarget()` 附带 `kind / label / hostile`；霹雳发射验收在 `firePLMissile()`，制导与碰撞在 `updatePlayerMissiles()`。修改锁定目标类型时必须同步维护敌我标记
- 加力倍率集中在 `BOOST_MULT`（速度 / 尾焰 / 引擎声共用）；机炮准星预测在 `updateGunAim()`
- 敌方单位：射程 / 数量常量在「敌方单位」段顶部（`AAA_RANGE` / `SAM_RANGE` / `ENEMY_MAX`）；自动逻辑分别在 `updateAAA()` / `updateSAM()` / `updateEnemies()` / `updateThreats()`；玩家受击与血量在 `damagePlayer()`（上限 `G.hpMax`，默认 32）
- 投弹落点预测与图标在 `updateAim()`（弹道必须与 `dropBomb` 保持一致）；炸弹威力问题先查 `BOMB_RADIUS` 与 `spawnExplosion(pos, 3.6)` 的第二个参数
